# Linguagem C — Algoritmos e Pensamento Computacional

Nesta aula, foram estudados conceitos básicos da linguagem **C**, com foco em algoritmos e pensamento computacional.

## 📚 Conteúdos estudados

* Estrutura básica de um programa em C
* Variáveis e tipos de dados (`int`, `float`, `char`)
* Entrada e saída de dados com `scanf` e `printf`
* Operadores aritméticos
* Cálculo de média
* Estruturas condicionais (`if`, `else`)
* Operadores de comparação e lógicos
* Estrutura de repetição `for`
* Estrutura de repetição `while`
* Uso de contadores
* Uso de valor sentinela
* Resolução de exercícios práticos

## 💻 Atividades

Foram desenvolvidas atividades envolvendo:

* Exibição de informações
* Operações matemáticas
* Cálculo de médias
* Verificação de maioridade
* Aprovação por média e frequência
* Tabuada utilizando `for`
* Contagem de números utilizando `while`
* Repetição até a entrada do valor `0`
* Contagem de notas maiores ou iguais a `6`

## 🎯 Objetivo

Praticar os fundamentos da linguagem C e desenvolver a lógica necessária para criar algoritmos utilizando **variáveis, condições, repetições e contadores**.
